Frontend Developer

Location: Kansas City, MO (Remote-First) Type: Full-Time Level: Mid to Senior

Join Pumpfiat as a Frontend Developer and build the beautiful, high-converting interfaces that thousands of growth teams rely on every day. You’ll own the client-facing experience — from landing pages that drive acquisitions to dashboards that deliver real-time campaign insights.

About the Role

As a Frontend Developer at Pumpfiat, you’ll work closely with product, design, and backend teams to create fast, accessible, and visually stunning experiences. We move quickly, ship often, and measure everything — your work will directly impact conversion rates, user satisfaction, and revenue growth.

This is a remote-first role with a preference for candidates in or able to collaborate effectively with the Kansas City, MO timezone.

Key Responsibilities

  • • Build and maintain responsive, high-performance landing pages and marketing sites using modern React and Tailwind CSS.
  • • Develop interactive client dashboards for campaign analytics, segmentation, and deliverability monitoring.
  • • Collaborate with designers to implement pixel-perfect UI and create reusable component libraries.
  • • Optimize frontend performance — ensuring fast load times and excellent Core Web Vitals scores.
  • • Contribute to A/B testing infrastructure and help run experiments that improve conversion rates.
  • • Champion accessibility, SEO best practices, and cross-browser compatibility.

What We’re Looking For

  • • 4+ years of professional frontend development experience.
  • • Strong proficiency in React (hooks, context, performance optimization) and modern JavaScript/ES6+.
  • • Expert-level experience with Tailwind CSS or similar utility-first frameworks.
  • • Experience building responsive, accessible, and SEO-friendly interfaces.
  • • Familiarity with TypeScript, Next.js, or similar frameworks is a strong plus.
  • • A portfolio demonstrating clean, conversion-focused UI/UX work.
  • • Ownership mindset — you care deeply about the end-user experience and business impact.

Nice to Have

  • • Experience with animation libraries (Framer Motion, GSAP).
  • • Background in growth, marketing tech, or SaaS products.
  • • Contributions to open-source projects or a strong GitHub presence.
